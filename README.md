# Lawn-Bowls-Planner
This app works on any device and with minimal effort, it will quickly and easily produce all the information needed to host most lawn bowls tournaments from a simple roll up to a complicated section play with double life knockout brackets. There are options to optimize team numbers to allow for some teams to have 1 less or 1 extra bowler to eliminate byes, or automatically select the best game type for you based on the amount of bowlers that turn up. Or many other optional user inputs such as game type, number of rinks, green and bowler names etc. As well as auto saving your data you can save it as a file on your device for later. It can handle all the scorecard information including rink numbers, byes, timings and analyze the scores to find a winner. Scorecards, sections and brackets can also be printed for all bowlers to see. Free to use for the first 3 months.
