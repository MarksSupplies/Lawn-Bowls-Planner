# Lawn-Bowls-Planner
Free to use for the first 3 months. This app works on any device and with minimal effort it will produce all the information needed to host a lawn bowls tournament based on either the amount of bowlers or teams available. It can create the scorecard data including byes or balance the team numbers to allow for some teams to have an extra bowler to eliminate byes, or many other optional user inputs such as game type, number of rinks, green and bowler names etc. As well as auto saving your data you can save it as a file on your device for. It can easily and quickly cater for a quick roll up or a major tournament and create all the scorecard information including rink numbers, byes, timings and analyze the scores to find a winner.
